# SoftwareSecurity
Homeworks of the course Security in Software Applications, 2024-2025, La Sapienza.

# Projects
## Homework 1 - Flawfinder

If you have UV installed, it is easy to test flawfinder inside the UV solution directory by simply running `uv run flawfinder`.

## Homework 2 (and 3) - Fuzz ImageMagick with AFL++

It is possible to easily replicate the fuzzing process since it is all packed and ready in a docker file. Simply build a container and run it. Then, run the `./fuzz.sh` script and wait for the AFL++ to do the work!


## Homework 3 - Echidna

The same procedure for homework 2 holds also for the homework 3.
